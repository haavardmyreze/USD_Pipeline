# Quiet Reader

Bring your own Markdown and read in a calm, focused layout.

## What this viewer does

- Opens documents from the **Library** — no file picker needed
- Renders clean typography with eight themes
- Lets you switch between continuous flow and paged mode

> A good reading view disappears and lets the text lead.

### Example checklist

- [x] Beautiful spacing
- [x] Comfortable line length
- [x] A4-like page mode

const mood = "Apple + Bear + Notion";

## Adding documents

Drop `.md` files into the `markdown-viewer/library/` folder in this repository. They appear in the Library menu automatically — no configuration required.
